# digital-dna-matching-mutation-detection-system

## Overview
This project implements a digital logic system to compare DNA sequences and detect mutations using combinational and sequential logic techniques.

## Objective
To design and simulate a system capable of:
- Matching DNA base sequences
- Identifying mismatches and mutations
- Demonstrating the concept through simulation and hardware implementation

## Tools Used
- Digital logic design techniques
- Logic simulation software- Proteus
- Hardware implementation using logic ICs,countrs, etc.

## Methodology
1. Represented DNA bases using binary encoding.
2. Designed comparison logic to detect sequence matches.
3. Implemented mutation detection circuitry.
4. Verified functionality using simulation and hardware testing.

## Results
Two models (Model 1- Single-Stranded DNA matching, Model 2- Double-Stranded DNA Matching) were successfully designed and simulated, and were implemented in hardware, as well.
